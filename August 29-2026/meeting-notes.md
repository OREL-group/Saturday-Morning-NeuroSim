How much error is driven by seed values in a simulation?  The error driven by a seed value depends on the number of runs in your simulation, and it shrinks as you increase that number. 

What a Seed Does
* * a seed is a starting number for a pseudo-random number generator.
* different seeds create different sequences of random numbers.
* * a single seed does not cause a permanent mathematical mistake, but it gives one specific random outcome.
 

How to Control It
* Increase Iterations: Run more trials so the choice of seed stops changing the final average.

* Averaging Seeds: Run your simulation multiple times with different seeds and average the final outcomes.

* Common Random Numbers: Use the exact same seeds when comparing two different scenarios so the random noise cancels out.
